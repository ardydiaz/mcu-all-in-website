# MCU All-in-One Frontend

A responsive React and Vite landing page that serves as a central directory for MCU websites and services.

## Run locally

```bash
npm install
npm run dev
```

The development command starts both the Express API on port `3000` and Vite
on port `5173`. The React admin interface is available at `/admin`. Use
`npm run dev:web` only when the API is already running.

## Build

```bash
npm run build
```
